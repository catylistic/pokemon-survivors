# Pokémon Survivors

A Vampire Survivors–style fan game with Pokémon. Pick a starter, survive 15 minutes of wild Pokémon, then beat the region's legendary to unlock the next region: Kanto through Paldea.

**Play:** https://catylistic.github.io/pokemon-survivors/

- Move with WASD / arrow keys (or hold the mouse / touch). Attacks fire automatically.
- Type matchups, STAB, evolution, evolving moves with held items, catchable shiny allies.
- 9 regions, high scores, achievements and an original chiptune soundtrack.

Everything is in a single `index.html`. Sprites load from the [PokeAPI sprites](https://github.com/PokeAPI/sprites) repository.
